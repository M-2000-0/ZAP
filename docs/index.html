Why Zpx?

Token Efficient

30-60% fewer tokens than Python or JavaScript. Faster generation, lower cost, fewer errors.

One Language

Backend, frontend, database, config — all in one syntax. No context switching.

AI-Native Design

First language designed for AI code generation, not human readability on paper.

Self-Hosting

The Zpx interpreter is written in Zpx. Proves the language is complete.

Zero Boilerplate

248+ builtins. No imports needed for most tasks.

Full-Stack

Schemas, APIs, HTML rendering — all in one file.

Quick Start

# Install
pip install zpx-lang

# Run your first program
echo 'print("Hello from Zpx!")' > hello.zpx
zpx run hello.zpx

# Or from source
git clone https://github.com/M-2000-0/ZPX.git
cd ZPX
python -m src run examples/hello.zpx

Syntax Overview

Zpx uses indentation-based blocks with : and # for comments.

Variables

let name = "Zpx"
let version = 42
let pi = 3.14159

Functions

fn add(a, b):
    ret a + b

# Expression form (implicit return)
fn double(x) x * 2

Classes

class Dog:
    fn init(self, name):
        self.name = name
    
    fn bark(self):
        print(self.name + " says woof!")

Control Flow

if x > 0:
    print("positive")
el:
    print("non-positive")

for i in range(10):
    print(i)

while running:
    process()

Pattern Matching

match status:
    "active": print("Active")
    "inactive": print("Inactive")
el:
    print("Unknown")

Comprehensions

let nums = [1, 2, 3, 4, 5]
let doubled = [x * 2 for x in nums]
let evens = [x for x in nums if x % 2 == 0]
let squares = {x: x * x for x in nums}

Type Annotations

fn find_user(users: list[dict[str, any]], id: int) -> dict[str, any] | none:
    for u in users:
        if u["id"] == id:
            ret u
    ret none

Contracts

@requires(amount > 0)
@ensures(balance >= 0)
fn withdraw(amount: float):
    balance = balance - amount

Examples

REST API

schema User:
    name: str
    email: str

api GET "/users/{id}":
    let user = query("SELECT * FROM users WHERE id = ?", id)
    render_user(user)

Data Pipeline

let data = read_file("data.json")
    |> json_parse
    |> filter(x => x.active)
    |> map(x => x.name)
    |> sort
    |> join(", ")
